# ANNIS conversion

Sonja Zeman and [@matthias-stemmler](https://github.com/matthias-stemmler) converted our data from Turtle to ANNIS by merging the RDF data with ReM 1.0 sources using a designated [`rem-treebank-annis converter`](https://github.com/matthias-stemmler/rem-treebank-annis).
